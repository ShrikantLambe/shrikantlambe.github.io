11 / hr-copilot
AI Agent · Recruiting Analytics

HR Analytics Copilot — a dashboard that writes its own SQL.

A recruiting-funnel dashboard with a dual-path AI assistant: numeric questions are answered by an LLM writing SQL that runs client-side against DuckDB-WASM, returning both the number and the query that produced it; interpretive questions are answered from a findings knowledge base with citations. There's no backend database — data lives in local CSVs — and the LLM key stays inside a single server-side API route, never reaching the client bundle. Ships with a full demo mode so the live app works end-to-end with zero key and zero flaky-network risk.

-- customer feedback analysis inside Snowflake
SELECT
  customer_id,
  SNOWFLAKE.CORTEX.SENTIMENT(support_notes) AS sentiment,
  SNOWFLAKE.CORTEX.CLASSIFY(
    support_notes, ['billing', 'outage', 'feature']
  ) AS category,
  SNOWFLAKE.CORTEX.COMPLETE(
    'llama3-70b',
    CONCAT('Summarize: ', support_notes)
  ) AS summary
FROM customer_feedback
WHERE region = 'EMEA';
